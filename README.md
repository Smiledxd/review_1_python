## Utilidades (`tools/`)

- `python3 tools/generar_notebook.py`: genera el notebook (es la fuente de verdad; no lo edites a mano) y lo valida con `nbformat`.
- `python3 tools/verificar_notebook.py`: ejecuta el notebook con soluciones y con plantillas, recalcula los valores esperados de forma independiente y comprueba las trampas del reto final.

Requieren `nbformat` (y `matplotlib` para la celda del gráfico).
